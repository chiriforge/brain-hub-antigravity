# Git Operations Policy

## 1. Git Push Condition
- `git push` is allowed ONLY when the user **explicitly requests or instructs** it in the prompt (e.g. "push lên github cho tôi", "hãy git push", "push code").
- In all other automatic workflows, keep changes strictly local until explicitly confirmed by the user.

## 2. Local Commits & Staging
- Proactively stage files (`git add`) and create clean, atomic commits (`git commit`) locally whenever completing a feature or bugfix.
